# Locale / i18n

## Default

Daily debug locale is **`zh-CN`**. English pack: `en`.

## Sources (UI as Config)

| File | Role |
|------|------|
| `ui/default.toml` → `locale` | Default locale id |
| `ui/i18n/{locale}.toml` | String catalog |
| CLI `--locale` | Overrides file default |

## Scope

Tray menu / status, main dashboard chrome, vault section labels, desktop toasts.

Hardcoded product name **MCP Guard** stays Latin in both locales.
